# GT-Meet 화상회의

팀 회의용 화상회의 프로그램입니다. 화상·음성 회의, 화면 공유, 채팅, 파일 보내기, 녹화, 녹취록, 중요 장면 자동 캡처를 지원합니다.
한국어 · English · 日本語 · 简体中文

## 설치

### Windows
1. `GT-Meet-Setup-x.x.x.exe`를 받아 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
3. 바탕화면의 **GT-Meet** 아이콘으로 실행합니다.

### 안드로이드
1. 휴대폰에서 위 **최신 버전 내려받기**를 열고, **Assets**를 눌러 펼친 뒤 `.apk` 파일을 누릅니다.
2. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 **설치**를 누릅니다.

### 아이폰 · 아이패드
- 설치할 것이 없습니다. **받은 초대 링크를 누르면 Safari에서 바로 참여**합니다.
- 자주 쓴다면 Safari로 <https://gipter.github.io/gt-meet-releases/> 를 열고 **공유(□↑) → 홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.
- 카카오톡 안에서 링크가 열려 카메라가 안 되면, 메뉴에서 **Safari로 열기**를 누르세요.

## 사용 방법

**회의 열기 (Windows)**
1. 이름을 넣고 **새 회의 시작**을 누릅니다.
2. 회사 밖 사람도 참여한다면 첫 화면의 **🌐 외부 접속**을 켭니다.
3. **✉ 초대문 복사**를 눌러 메신저나 메일로 보냅니다.
4. 참가자가 들어오려 하면 **수락**을 누릅니다.

**회의 참여**
- **초대 링크를 누르기만 하면** 회의 ID와 비밀번호가 채워집니다. 이름을 넣고 **참여 요청**을 누르면, 호스트가 수락한 뒤 들어갑니다.
- 앱에서는 **회의 참여** 칸에 초대문을 붙여 넣어도 됩니다.

자세한 사용법은 프로그램 안의 **❓ 도움말**(F1)을 보세요.

## 업데이트

- **Windows와 안드로이드:** 하루에 처음 실행할 때 새 버전이 있는지 확인하고, 있으면 업데이트할지 묻습니다.
- **아이폰 웹앱:** 열 때마다 자동으로 최신 버전이 됩니다.
- **필수 업데이트:** "필수 업데이트" 안내가 나오면 업데이트해야 새 버전 사용자와 회의할 수 있습니다.

## 개인정보

- 영상, 음성, 파일은 참가자끼리 암호화해서 직접 주고받고, 서버에 저장되지 않습니다.
- 녹화, 녹취록, 캡처는 각자의 기기에만 저장됩니다. 녹화하기 전에 참가자의 동의를 받으세요.
- 녹취 기능은 브라우저의 음성 인식을 쓰기 때문에, 음성이 Google이나 Microsoft 서버로 보내질 수 있습니다. 민감한 회의에서는 녹취를 끄세요.

## 알아 둘 점

- 한 회의에 6~8명까지 원활합니다.
- 회의는 Windows 앱에서만 열 수 있고, 휴대폰과 태블릿은 참여만 할 수 있습니다.
- 보안이 아주 엄격한 회사망에서는 영상 연결이 안 될 수 있습니다.
